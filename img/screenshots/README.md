# 当前界面素材

<!-- v2026.10.14：替换 2026-05 的旧图库，建立图像来源和可复现的生产视图采集流程。 -->

文档基线：**v1.6.12**。本目录展示工作台或专业工具内页，不包含重画的产品界面。
采集使用当前生产 SwiftUI/AppKit 视图，独立输出 **zh-Hans / en** 两套 Retina JPEG。
图片清单与摘要见 [manifest.json](manifest.json)。

| 文件前缀 | 场景 | 数据来源 |
|---|---|---|
| `01-analyze` | 普通工作台的空间分析 | `NSTemporaryDirectory()` 内四个自行创建的示例目录，由生产扫描/投影生成。 |
| `02-clean` | 普通清理的分类与审阅入口 | 隔离的示例候选和容量，不代表真实用户扫描结果。 |
| `03-status` | 普通状态看板 | 采集时本机只读系统读数，不是固定百分比或性能基准。 |
| `04-tree` | 专业树形结果区 | 示例目录、数量、日期与容量；仅展示结果组件。 |
| `05-large-files` | 专业大文件结果区 | 示例文件、类型和容量；`/Users/example` 是纯展示路径，不读取该目录。 |
| `06-row-actions` | 操作列示例说明 | 生产帮助组件，没有文件身份、选择或业务回调。 |

例如 `01-analyze-zh-Hans.jpg` 和 `01-analyze-en.jpg` 分别用于两种语言页面。
图片中的文件夹名/文件名是示例数据，仍保持文件名原文，不作为 UI 翻译处理。

## 复现

该采集在源码仓库进行（需要源码访问权限），本发行仓库只同步经过检查的素材。
从源码仓库根目录运行：

```bash
./Scripts/screenshots.sh
./Scripts/screenshots.sh --output-dir build/documentation-capture/images
```

该命令只运行明确开启的 `DocumentationScreenshotTests`；默认包测试会跳过图片生成。
它不启动 AmuxAIClean、不扫描真实 HOME、不移动文件、不调用 AI，也不改变系统权限。
Undo、白名单及测试设置与生产数据隔离，临时文件与设置在结束后清理。

离屏截图不构成 C4/C5，也不能证明所有入口已经完成真实交互。失败弹窗、严格确认等交互边界
另按[删除合同](../../docs/USER_GUIDE.md#4-删除确认失败与恢复)与质量台账验收。

## 更新时的检查

逐张打开中英文图片，检查字体、背景、裁切、行操作和路径；检查页面图片引用和下载链接。
原生表格需要与窗口一致的背景，不能接受透明图片在网页上出现黑底。
输出使用 JPEG 保留 Retina 字体并压缩渐变背景，减少首页加载体积。

公开发行仓库使用同一批文件，不能把旧图与新文案混用。更新素材与说明不改变已发布 DMG 或源码 tag。

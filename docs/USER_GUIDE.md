## 1. 先找占用，再选择清理范围

新窗口默认打开普通模式的“分析”。从“扫描范围”选择磁盘或文件夹，完成扫描后：

- 矩形面积表示已测得的磁盘占用；点击文件夹可以继续下钻。
- 左侧目录列表与搜索帮助定位项目；面包屑可返回上层。
- 较小项目会合并显示，进入对应明细仍可查看成员。
- 物理占用、逻辑大小、文件数与可清理建议是不同指标；图块面积不能当作可清理容量。

![普通模式空间分析](../img/screenshots/01-analyze-zh-Hans.jpg)

权限、扫描预算、跨卷边界或产品保护范围可能使结果不完整。先查看界面给出的具体范围和原因；
完全磁盘访问可以改善部分受保护目录的可见性，但不能解除产品对敏感数据的保护。

## 2. 普通工作台的四个栏目

| 栏目 | 适合的任务 | 操作要点 |
|---|---|---|
| 分析 | 查看磁盘或文件夹占用 | 选择范围、扫描、下钻和搜索。 |
| 清理 | 审阅常见清理候选 | 选择扫描阶段，等待结果，进入预览清理再确认。开发缓存需主动选入。 |
| 优化 | 用户态维护与启动代理检查 | 逐项阅读工具说明；传统启动代理是只读检查，现代登录项通过系统设置管理。 |
| 状态 | 观察系统运行情况 | 查看 CPU、内存、磁盘、电池、网络、运行时间和散热读数。 |

![普通清理结果示例](../img/screenshots/02-clean-zh-Hans.jpg)

绿色建议表示当前证据下的安全候选；需要确认的项目要逐项审阅。扫描不会自动删除文件。
“预览清理”是审阅入口，最终肯定操作才提交回收请求；不能把它当作已经完成清理。

## 3. 专业模式与行操作

在窗口顶部切换专业模式。侧栏包含批量扫描、推荐类目、自定义路径、资源库浏览、大文件、
应用工具及开发者工作流。路径输入框和拖入文件夹可以发起对应范围的分析。

树形视图用于逐层浏览，清单用于过滤和批量勾选。大文件默认至少 100 MB、Top 200，
可调整阈值，按大小或修改时间排序，按类型筛选，并使用 Quick Look。

![专业树形结果区示例](../img/screenshots/04-tree-zh-Hans.jpg)

| 操作 | 含义 |
|---|---|
| ✨ | AI 辅助分析；需要在设置中主动启用并配置服务。建议不授予删除权限。 |
| 托盘 | 加入“稍后处理”，集中审阅不同目录的候选。 |
| 废纸篓 | 检查当前项目并进入相应确认流程。 |
| 操作列表头问号 | 打开不涉及真实文件的按钮示例说明。 |
| 窗口右上角问号 | 重新打开当前模式的控件引导。 |

![操作列示例说明](../img/screenshots/06-row-actions-zh-Hans.jpg)

不可用的操作可能来自测量未结束、项目受保护、资格未通过或当前操作占用。查看该项目的提示，
不要把所有禁用状态都理解成没有完全磁盘访问。

## 4. 删除确认、失败与恢复

**普通模式**提供详细审阅。**专业模式**对普通候选使用简洁确认；对允许覆盖的风险直接进入
严格确认，需要输入 `DELETE`。这类覆盖适用于特定厂商路径或扫描不完整风险，并会在执行前重新验证。

严格确认不能跨越系统保护边界、HOME / Library 整根保护、路径穿越、越界和真实系统权限。
它也不能代替内部清理记录正常保存；记录保存失败时本次请求不会提交，文件仍留在原处。

- **完整成功**：短暂成功提示，不需要额外关闭结果窗口。
- **失败、部分成功或未提交**：弹窗说明具体原因；部分成功时只把确实回收的项目计入历史。
- **结果待核对**：系统提交状态未知时，先查看说明并等待核对，避免把同一请求重复提交。

文件清理进入系统废纸篓。在“最近清理”中可尝试恢复；对应对象必须仍在废纸篓且身份匹配。
清空废纸篓、在外部移动或替换对象后不能保证恢复。历史保存的是已接受事实，不等于所有请求都成功。

Apple 开发者工作流中的 **Simulator Device / Runtime** 使用明确标识的系统托管卸载，
不是废纸篓回收，不能通过最近清理恢复。其它文件类候选仍走废纸篓。

## 5. 常用专业工具

| 工具 | 任务与边界 |
|---|---|
| 大文件 | 查看大体积文件；删除前检查内容与用途，大小本身不是安全依据。 |
| 重复文件 | 在本机读取候选字节计算哈希；选定保留副本后审阅待回收项，执行前重新验证内容和身份。 |
| 应用占用 / 卸载 | 根据应用身份及文件证据检查关联数据；关联残留不能保证覆盖应用留下的所有文件。 |
| 开发者构建产物 / 工作流 | 按生态查看构建输出、依赖缓存及版本资源。再生成或重新下载会花时间，确认项目状态后操作。 |
| Homebrew | 先检查包信息和依赖；软件包命令与文件回收按各自工具的确认说明执行。 |
| 端口清理 | 查看监听进程并确认后操作；不是文件删除，终止进程前应确认正在运行的工作。 |
| 稍后处理 | 临时汇总候选；加入集合不会删除文件。 |

## 6. 设置、升级与反馈

- 语言支持简体中文与 English，外观跟随或使用应用提供的设置。
- AI 默认关闭；主动启用并请求后，上下文发送到自行配置的服务。字段与默认脱敏见[隐私政策](../PRIVACY.md)。
- 更新检查来自 [CarGuo/AmuxAICleanRelease](https://github.com/CarGuo/AmuxAICleanRelease/releases)，启动检查可在设置中关闭。
- Sentinel 默认关闭；启用前查看设置说明，卸载 App 前先关闭并确认未注册。
- 支持从 **1.6.2 及以后**升级；不自动迁移 1.5.9、1.6.0、1.6.1 的旧配置、服务身份或撤销历史。

## 当前入口

| 入口 | 已有实现 |
|---|---|
| 普通工作台 | 分析、清理、优化、状态；新窗口默认普通模式。 |
| 空间分析 | 矩形空间图、目录列表、下钻、搜索、较小项目明细。 |
| 专业扫描 | 推荐、整盘、开发者构建产物、常见软件缓存、自定义路径、树形与清单。 |
| 文件与应用 | 大文件、内容重复组及保留副本审阅、应用占用、卸载关联残留。 |
| 专业工具 | Homebrew、端口清理、Dart 工具、传统启动代理、用户态维护和开发者工作流。 |
| 清理交互 | 普通详细审阅；专业普通/严格确认；完整成功提示，失败/部分成功弹窗。 |
| 回收与恢复 | 文件移到系统废纸篓、最近清理记录、条件恢复；SQLite 保存执行事实并导入当前品牌旧历史。 |
| 引导 | 当前窗口控件引导、操作列表头示例、随时重新打开。 |
| 可选能力 | AI 默认关闭；Sentinel 默认关闭并运行当前用户 Agent。 |

实现入口不等于已对每种 OS、权限、数据规模和交互组合完成验收。
普通用户操作见[使用指南](USER_GUIDE.md)，边界见[删除合同](USER_GUIDE.md#4-删除确认失败与恢复)与[隐私政策](../PRIVACY.md)。
